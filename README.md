# System Design Atlas

Interactive decision map for common system-design scenarios. Walk from a **challenge** through **solutions** and the **blockers** in the way.

## Stack

Vite · React · TypeScript · Tailwind CSS · React Flow · Dagre · Fuse.js

## Local

```bash
npm install
npm run dev
```

Open the URL Vite prints (base path `/sysdesign-atlas/`).

## Build

```bash
npm run build
npm run preview
```

## Deploy

Pushes to `main` build `dist` and deploy via GitHub Pages (`base: /sysdesign-atlas/`).
